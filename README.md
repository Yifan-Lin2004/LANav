# LANav

Project resources for **Beyond Transformers with a linear attention policy for open-vocabulary object goal navigation**.

- [Project page](https://yifan-lin2004.github.io/LANav/)
- [Real-world demonstration video](https://yifan-lin2004.github.io/LANav/video.html)
- [Watch or download the video](https://yifan-lin2004.github.io/LANav/video.html)
- [Paper on arXiv](https://arxiv.org/abs/2607.18794)

The project page presents Linear Attention-based Navigation (LANav), Weighted State-Expansion Linear Attention (WSLA), benchmark results, and a Unitree Go2 demonstration. Research code release is planned.

This is a static site. GitHub Pages should publish from the `main` branch and repository root. The `.nojekyll` file allows the HTML and assets to be served directly.
